# Pastport 1.4.0 for Mac

Rediscover pages from your Safari history in a new timeline. Select a page to see its recorded date and source, then find more pages from the same site. Pastport can also show sites that appear on multiple separate days in the selected history window.

Agent Trail suggests a small set of supported history topics and gathers an answer for each. Apple Intelligence runs on device when available; recorded-fact fallbacks are labeled. Review the evidence: an open page does not prove that you read it, booked something, or went somewhere.

The optional Alfred view can use a separately selected, trusted Batmobile helper to display repository references from an Alfred database. It does not expose clipboard text to the history assistant.

Pastport also has a new Mac icon. Safari access requires Full Disk Access. Photo activity and user-added screenshots remain optional and use the app's existing on-device Vision and privacy controls.
